# Digital CMOS Layout Design

## About This Repository

This repository contains my digital CMOS circuit design and layout implementations as part of my VLSI learning journey.

The projects focus on understanding basic digital logic circuits, transistor-level implementation, and CMOS layout design.

## Projects

The following circuits are included:

1. AND Gate
2. OR Gate
3. NOT Gate (Inverter)
4. NAND Gate
5. NOR Gate
6. XOR Gate
7. XNOR Gate
8. Half Adder
9. Full Adder
10. Schmitt trigger

## Tools Used

* Cadence Virtuoso

## Technology

* Process Node: 45 nm
* PDK: GPDK45
* Technology: CMOS

## Key Learning Areas

* CMOS Fundamentals
* NMOS and PMOS Transistor Design
* Digital Logic Design
* Schematic Design
* Layout Design
* Design Rule Check (DRC)
* Layout Versus Schematic (LVS)
